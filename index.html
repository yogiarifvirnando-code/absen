💾 Backup & Restore Data

📋 Catatan Penting:

  • • Backup rutin: Disarankan backup data setiap minggu atau setelah input nilai penting
  • • Format file: Data disimpan dalam format JSON yang aman dan dapat dibaca
  • • Data yang di-backup: Kehadiran siswa, nilai semua jenis penilaian, hari libur, dan pengaturan aplikasi
  • • Kompatibilitas: File backup dapat digunakan di perangkat lain dengan aplikasi yang sama

📤 Backup Data

Unduh semua data kehadiran dan nilai dalam format JSON

✅ Aman: Data akan diunduh ke perangkat Anda dan tidak dikirim ke server manapun

📥 Restore Data

Pulihkan data dari file backup

⚠️ Peringatan: Restore akan mengganti semua data yang ada saat ini

💡 Tips Penggunaan:

Kapan harus backup:

  • • Sebelum input nilai ujian penting
  • • Setiap akhir minggu
  • • Sebelum mengganti perangkat
  • • Sebelum reset data

Cara menyimpan backup:

  • • Simpan di folder khusus di komputer
  • • Upload ke Google Drive/OneDrive
  • • Kirim via email ke diri sendiri
  • • Simpan di flashdisk sebagai cadangan
